## ROLL DIE (4800-57 / 4800-61)

The workbook `谷R_新基準値` sheet layout:

| column group | content |
|---|---|
| `ネジサイズ` | thread **dia (inches)** · **TPI** · form — e.g. `0.3125` `-24` `UNJF` |
| `転造ダイス先端R 規格値(AS8879)` | tip-R spec min/max (mm and inches) |
| die DWG No. by `巾` (width) | `巾 60 / 80 / 100 / 150 mm`, `R 右ネジ` (right) / `L 左ネジ` (left) |

Selection is **by thread size only** — read `ネジサイズ` (dia + TPI), get the die drawing; width and hand
are separate columns (a setup choice), not a computed dimension.

| out | workbook | config | verdict |
|---|---|---|---|
| A | `ネジサイズ` dia, inches | `A = threadDia` (parsed from `thread_name`, inches) | **match** — exact-match rule (`tol_plus = tol_minus = 0`) |
| B | `ネジサイズ` TPI | `B = threadTPI` (parsed from `thread_name`) | **match** — exact-match rule |

`threadDia` / `threadTPI` come from `buildSpecContext` parsing `thread_name` (which arrives in two
spellings — `.3125-24UNJF` and `5/16-24UNF` — so it is parsed to a number, mixed fractions first;
see `.claude/rules/tooling-select.md` §"Thread-driven selection").

Die **width** (60/80/100/150 mm) deliberately carries **no rule** — every width for the thread is
returned, matching the workbook's multiple width columns per thread row.

**Family verdict: MATCH.** A die either cuts the thread or it does not — config keys the die on
`(threadDia, threadTPI)` with exact-match tolerances, which is exactly what the workbook's `ネジサイズ`
column selects on. Width/hand left unconstrained by design, as in the workbook.
