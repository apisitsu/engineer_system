## Which collet (routing) — approximation

Workbook routes **per part** by RACE vs SLEEVE. Config routes by:
`Type == "N"` → 4030-01, `Type == "F"` → 4030-02, else by **cnPrefix class**:
`[23,25,26,41,42,61,63]` → 4030-01, `[62,64,69]` → 4030-02.

- `tooling_spec_process.type` is not the workbook's `"N" or "F"` column (that column is per-P/N and
  a SLEEVE row in the workbook carries `N`), so the **cnPrefix fallback does the real routing**.
- It does not cleanly follow 「SLEEVE → ID grip」: `C61/C63` sleeves route to the **OD**-grip collet
  while `C62/C64/C69` route to ID-grip. A heuristic, not the workbook rule.
- **Masked in practice** by a 1,361-row `tooling_partno_map` (eval: KL-20 100 % top-1), so the formula
  is a fallback the plan rarely reaches.
