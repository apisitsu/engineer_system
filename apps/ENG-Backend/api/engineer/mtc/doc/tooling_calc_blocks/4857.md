## Spot-check: X-100 ARBOR (`4857/ARBOR.pdf`) — EXACT MATCH

Workbook inputs: `BALL ID(MIN) · SPH OD(MIN) · SPH TB · BALL BW · SPH SW`.
Sample row `4MHT25-60A`: ID 24.990 · OD 45.10 · TB 34.32 · BW 24.97 · SW 19.93 → **A 24.980 · B MIN 34.8 · C MAX 44.9 · D MIN 3.1**.

| out | workbook | config | sample | verdict |
|---|---|---|---|---|
| A | `ROUNDDOWN(BALL ID(MIN) − 0.01, 2)` | `floorN(idAft_min − 0.01, 2)` | 24.990−0.01 → **24.98** | **exact** |
| B | `ROUNDUP(SPH TB + 0.4, 1)` | `ceilN(TB + 0.4, 1)` (`TB = √(ball_dia² − race_width²)`) | 34.32+0.4 → ⌈**34.8** | **exact** |
| C | `ROUNDDOWN(SPH OD − 0.2, 1)` | `floorN(OD − 0.2, 1)` | 45.10−0.2 → **44.9** | **exact** |
| D | `ROUNDUP((BALL BW − SPH SW)/2 + 0.5, 1)` | `ceilN((ballWidth − sphWidth)/2 + 0.5, 1)` | (24.97−19.93)/2+0.5 → ⌈**3.1** | **exact** |

E/F/G/H/J/K on the sheet are fixed geometry / pick-from-a-list (`H: 12·15·18·20·22.5·24·30 から選択`) —
config computes only A–D (the 3-simultaneous-filter ceiling the audit measured on the 123-row shelf).

**All 4 computed outputs reproduce the workbook sample row exactly.**
